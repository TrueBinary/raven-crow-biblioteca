# Biblioteca do Corvo — Raven Crow

Página estática para link na bio, com curadoria original sobre política, história, filosofia e economia.

## Status

- Página criada e testável localmente. **Ainda não hospedada em URL pública.**
- Os botões levam a buscas da Amazon Brasil **sem rastreamento de afiliado**, porque nenhum ID Amazon Associados foi informado ou verificado.
- As recomendações são editoriais; não há preços, disponibilidade ou avaliações de compras inventados.
- O perfil Instagram/TikTok está configurado como `@ravencrowcc`, YouTube como canal `UC7QOwGdezKSy8NiaIalE9-w`.

## Como ativar afiliados

1. Inscreva o Raven Crow em https://associados.amazon.com.br/ e registre as contas/site de divulgação.
2. Após receber o ID de associado e confirmar a elegibilidade de usar links, substitua `const AMAZON_ASSOCIATE_TAG = '';` no `index.html` pelo seu ID real.
3. Confirme que os URLs gerados incluem `tag=` e que o aviso de publicidade aparece em cada cartão.
4. Hospede a página como site estático (Cloudflare Pages, GitHub Pages, Netlify ou hospedagem sua). Só depois coloque o endereço público na bio do Instagram/TikTok/YouTube.
5. Não publique mensagens afirmando ser associado antes de fazer a adesão.

## Divulgação e integridade editorial

Amazon exige a declaração "Como associado da Amazon, eu recebo por compras qualificadas" quando a afiliação está ativa, além de indicação próxima dos links remunerados. Não compre pelo próprio link. Não incentive compras de parentes/amigos para cumprir metas. Evite tráfego pago direto para páginas da Amazon sem revisão das políticas.

## Estratégia do Raven Crow

- Priorizar conteúdos de política, filosofia, história, economia e instituições.
- Monster Cast sai do núcleo editorial por desalinhamento de nicho.
- Manter o alvo de até 6 cortes/dia só quando existirem 6 ideias distintas, originais e com direitos/revisão suficientes. Não fazer cortes repetidos só para bater a meta.
- Para cada vídeo com livro relevante: CTA discreto "Livro citado/contexto na Biblioteca do Corvo — link na bio"; quando não tiver ligação orgânica, não incluir CTA comercial.
- Medir com UTMs somente o tráfego no site; não inventar conversão, não rastrear indivíduos por sub-tags de afiliado.
