# Migração do Raven Crow para Cloudflare — plano de implementação seguro

> **Agentes executores:** usar `superpowers:executing-plans` e `superpowers:verification-before-completion`. Executar cada tarefa com teste, prova e rollback; sem afetar o ambiente principal.

**Objetivo:** migrar `ravencrow.cloud` do Render para Cloudflare Workers Static Assets + R2, incluindo HTML, imagens, carrosséis, 73 vídeos e as URLs `/clips/<sha>.mp4`, sem alterar n8n, daemon, esteira, Buffer ou históricos.

**Arquitetura:** GitHub continua sendo a fonte do código editorial. Worker serve os arquivos estáticos; bucket R2 privado ligado ao Worker serve mídia grande com GET, HEAD e Range, preservando as URLs. Render não deve ser removido até concluir a migração e a validação.

**Origem:** `TrueBinary/raven-crow-biblioteca`. **Site:** `https://ravencrow.cloud`. **Prévia:** `https://raven-crow-migracao-stage.gui15787.workers.dev/`.

- Render `raven-crow-biblioteca` está **suspended** por `billing`, respondendo HTTP 503 na origem e no domínio.
- Cloudflare conta `f6140a337d3b05e5e27c7f64ed166134`: zona `ravencrow.cloud` criada, ID `e1d1e720223512ed47da095648798f70`, **pending**.
- Nameservers atuais: `lunar.dns-parking.com` e `solar.dns-parking.com`. Nameservers futuros designados: `ace.ns.cloudflare.com` e `sandy.ns.cloudflare.com`. **Não trocar ainda.**
- Cloudflare importou 3 registros DNS: `A @ -> 216.24.57.1`, `CNAME www -> raven-crow-biblioteca.onrender.com`, `TXT @` de verificação Google. A e CNAME ficaram **DNS only**, reproduzindo o comportamento atual até a mudança controlada.
- Git checkout `public/`: 346 arquivos, 2.034.519.220 bytes, incluindo 73 MP4 (`public/clips` ~1,85 GiB). **39 vídeos ultrapassam 25 MiB**, limite por arquivo de Workers Static Assets.
- R2 ainda **não habilitado** nesta conta: API devolveu `10042 Please enable R2 through the Cloudflare Dashboard`. É ação necessária do proprietário (pode requerer cadastro de cobrança).
- Worker isolado `raven-crow-migracao-stage`: versão temporária que consulta os arquivos públicos do GitHub, **não usa Render**. Teste HTTP: 18/18 URLs do sitemap = 200; homepage, CSS/HTML, notícias, coluna, biblioteca, logo, robots, sitemap e verificação Google = 200; MP4 grande retorna HEAD=200 e Range=206 com 16 bytes.
- Fonte do staging é GitHub Raw, **não apropriada como CDN de vídeo permanente**: limites, disponibilidade e uso aceitável da plataforma exigem importar arquivos para R2 antes do cutover.

## Restrições de segurança permanentes

- NÃO alterar n8n, daemon, ReservaGPT, publicador, Buffer, vídeos aprovados ou seus ledgers. Evitar upload duplicado de MP4.
- NÃO fazer force push, reset hard, alterações em worktrees sujas, ou substituir arquivos de outros agentes.
- NÃO expor tokens em Git, logs ou no frontend.
- NÃO mudar nameservers, ativar rota no domínio de produção, desligar serviços ou criar cobrança sem confirmar que o conteúdo já está disponível.
- Mudanças em Git: usar branch isolada; deploy de código do Worker somente na prévia até os gates finais.
