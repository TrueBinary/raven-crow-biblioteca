# Raven Crow IndexNow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Avisar o IndexNow sobre alterações editoriais efetivamente publicadas no Raven Crow, com fila persistente e comprovantes de envio.

**Architecture:** Uma tarefa Windows independente lê o SHA do último release bem-sucedido e compara snapshots editoriais desse commit. Ela verifica as páginas públicas, mantém pendências em SQLite e envia lotes ao IndexNow, sem participar do caminho crítico de publicação. O Worker e o inventário existentes já servem o arquivo de chave `.txt`.

**Tech Stack:** Python 3.11+ e biblioteca padrão (`sqlite3`, `HTMLParser`, `urllib`, `unittest`), PowerShell, Windows Task Scheduler; regressões existentes com Node `node:test`.

**Spec:** `D:\YDL GUI\2026-10-31\me-ajude-a-configurar-samautomation-workflows\docs\superpowers\specs\2026-11-10-indexnow-design.md`.

## Global Constraints

- Host permitido: `https://ravencrow.cloud`, HTTPS, sem porta explícita, query string, fragmento ou credenciais.
- Preservar a tarefa `Raven Crow - release site R2` e seu intervalo de 15 minutos.
- Não alterar Worker, DNS, n8n, Buffer, agentes, vídeos, carrosséis ou branches de outros operadores.
- Runtime: Python 3.11+; somente biblioteca padrão; testes Python com `unittest` e regressão Worker com `node:test`.
- Nova tarefa: `Raven Crow - IndexNow`, intervalo de 5 minutos, janela máxima de 120 segundos, instância concorrente ignorada.
- Endpoint: `https://api.indexnow.org/indexnow`; lote máximo de 100 URLs; timeout por requisição de 10 segundos.
- Chave: 32 caracteres hexadecimais minúsculos, gerados uma vez; arquivo público `/<chave>.txt` em UTF-8 sem BOM, contendo exatamente a chave.
- Dados locais e runtime: `D:\CorteFlow\ops\indexnow`; não versionar estado nem configuração local.
- Só um SHA registrado em `last-released-sha.txt` pode originar notificações; não usar `origin/main` como prova de publicação.
- A primeira execução cria uma linha de base sem enviar o acervo antigo.
- Falha do notificador não modifica o marcador de release nem bloqueia a publicação.
- Nenhum teste automatizado faz envio real ao IndexNow ou registra tarefa no Windows.

## Review Focus

- Mesma URL muda durante retry: substituir a pendência antiga e impedir que uma resposta antiga confirme o fingerprint novo — testes nas tarefas 2 e 4.
- Página pública ainda entrega versão antiga apesar do marcador: adiar envio, comparando fingerprint público com o commit — tarefas 1 e 4.
- Arquivo removido do Git permanece no R2 sem exclusão: não notificar remoção até confirmar 404/410 — tarefa 4.
- Processo interrompido ou duas instâncias: preservar fila e impedir confirmação por lease vencido; reenvio após POST sem gravação é possível — tarefa 2.
- Windows sem sessão/PC desligado: usar a disponibilidade existente, registrar horário perdido e nunca afirmar funcionamento 24/7 — tarefa 5 e aceitação da tarefa 6.
